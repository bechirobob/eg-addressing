## Finalidad

Este manual define cómo operar, mantener, respaldar y atender el sistema durante piloto controlado y preparación institucional.

## Operación diaria

- Verificar salud de API, portal administrativo, base de datos, almacenamiento y caché.
- Revisar solicitudes, evidencias, reportes y cola de publicación.
- Mantener usuarios activos con el menor privilegio necesario.
- Registrar incidencias y acciones de mantenimiento.

## Mantenimiento

- Respaldar base de datos y evidencias antes de cambios importantes.
- Probar restauración de respaldo en entorno controlado.
- Actualizar documentación cuando cambien módulos, endpoints o reglas.
- Separar datos de prueba de datos institucionales.

## Soporte

- Canalizar errores operativos por responsable de sistema.
- Documentar pasos de reproducción, impacto y resolución.
- No publicar datos sensibles en reportes de soporte.

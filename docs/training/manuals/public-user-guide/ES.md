## 1. Cómo usar este manual

Este manual es una guía de capacitación para usuarios públicos. Puede usarse en una sesión presencial, en una capacitación corta o como documento de consulta.

Lea primero las reglas de privacidad. Después avance por los módulos en orden. Cada módulo explica qué debe hacer, por qué importa, los pasos correctos y los errores que se deben evitar.

La ubicación enviada inicia una revisión; el estado público se explica en la sección 10.

## 2. Audiencia y responsabilidades

Este manual es para ciudadanos que desean enviar una ubicación para revisión, residentes que necesitan comprobar el estado de una solicitud, empresas que necesitan entender cómo se revisa una ubicación y personal de atención pública que ayuda a otros usuarios a completar el proceso.

Responsabilidades principales:

1. Escribir información clara y verdadera.
2. Revisar que el punto de ubicación sea correcto antes de enviar.
3. Evitar datos sensibles innecesarios en campos públicos.
4. Conservar el código o número de seguimiento.
5. Consultar el estado público antes de asumir que un registro está publicado.

## 3. Resultados de capacitación

Al terminar este manual, el usuario debe poder:

1. Explicar qué es una solicitud de ubicación.
2. Enviar una ubicación con datos claros.
3. Entender qué significa la precisión GPS.
4. Comprobar un código de dirección.
5. Hacer seguimiento de una solicitud.
6. Distinguir entre una ubicación enviada, un caso en revisión y un registro publicado.
7. Saber dónde buscar ayuda cuando una solicitud no avanza.

## 4. Términos clave

Solicitud de ubicación: información enviada por un usuario para que una ubicación sea revisada.

Ubicación enviada: solicitud que ya fue enviada al sistema y espera revisión.

Código de dirección: código público usado para identificar o comprobar una ubicación.

Precisión GPS: estimación de qué tan cerca está el punto capturado de la ubicación real.

Evidencia de ubicación: información que ayuda a confirmar dónde está el lugar.

Registro oficial: registro revisado dentro del flujo oficial.

Listo para aprobación: el caso está preparado para revisión autorizada.

Estado público: indica si un registro no es público, está retenido internamente o está publicado.

Bloqueo de publicación pública: control que impide publicar información antes de la autorización correspondiente.

## 5. Reglas de privacidad y seguridad

Importante: no escriba números completos de documentos de identidad, contraseñas, datos bancarios, información médica ni datos sensibles innecesarios en los campos públicos de una solicitud.

Reglas básicas:

1. Use solamente la información necesaria para identificar la ubicación.
2. No comparta el enlace de seguimiento con personas que no deban verlo.
3. Revise la información antes de enviar.
4. No use una solicitud de ubicación para hacer denuncias no relacionadas con direcciones.
5. Si una ubicación involucra información sensible, pida orientación a un operador autorizado.

## 6. Módulo 1: visión general del servicio público

Este módulo explica el propósito del servicio público.

El sistema ayuda a registrar, revisar y consultar ubicaciones de forma ordenada. El objetivo es apoyar servicios públicos, entrega, planificación, atención ciudadana y verificación de direcciones.

Un usuario público puede:

1. Enviar una solicitud de ubicación.
2. Comprobar un código de dirección.
3. Hacer seguimiento de una solicitud.
4. Reportar una corrección pública cuando la información visible necesite revisión.

Un usuario público no puede:

1. Aprobar registros oficiales.
2. Publicar direcciones finales.
3. Emitir certificados oficiales.
4. Crear señalización física.
5. Ver datos sensibles de revisión interna.

El usuario público inicia o consulta el proceso; la decisión institucional se explica en la sección 10.

## 7. Módulo 2: enviar una solicitud de ubicación

Este módulo enseña cómo enviar una ubicación para revisión.

Procedimiento:

1. Abra la página pública para registrar una ubicación.
2. Lea la advertencia de piloto controlado.
3. Seleccione o confirme la provincia correspondiente.
4. Permita la captura GPS si está disponible y es seguro hacerlo.
5. Revise el punto mostrado en el mapa.
6. Si el punto no es correcto, corrija la ubicación manualmente según las instrucciones de la página.
7. Escriba una descripción clara del lugar.
8. Añada una referencia sencilla, como edificio cercano, carretera, barrio o punto conocido.
9. Revise la precisión GPS si aparece en pantalla.
10. Envíe la solicitud solamente cuando la información sea correcta.
11. Guarde el código o número de seguimiento.

Ejemplo de capacitación: una persona desea registrar la entrada principal de una pequeña tienda. El usuario coloca el punto en la entrada, escribe el nombre del negocio, añade una referencia cercana y envía la solicitud. El sistema guarda la ubicación como ubicación enviada para revisión.

Errores que se deben evitar:

1. Colocar el punto sobre una calle diferente.
2. Escribir una descripción demasiado corta, como solo “mi casa”.
3. Enviar una ubicación sin revisar el mapa.
4. Poner datos sensibles completos en notas públicas.
5. Asumir que el envío ya completó todo el proceso.

## 8. Módulo 3: comprobar un código de dirección

Este módulo enseña cómo comprobar si un código de dirección tiene información pública disponible.

Procedimiento:

1. Abra la página pública de comprobación o prueba de dirección.
2. Escriba el código exactamente como aparece.
3. Revise si el sistema reconoce el código.
4. Lea el estado público mostrado.
5. Si hay información pública disponible, confirme que corresponde al lugar esperado.
6. Si el código no aparece o no es público, no asuma que es inválido; puede estar pendiente de revisión o retenido internamente.

Cómo leer el resultado:

1. Código reconocido: el formato del código puede comprobarse.
2. Información pública disponible: existe información publicada para consulta pública.
3. No público todavía: el caso puede estar pendiente, retenido internamente o no aprobado para publicación.
4. No encontrado: revise si el código fue escrito correctamente.

Importante: un código reconocido no siempre significa que exista información publicada.

## 9. Módulo 4: hacer seguimiento de una solicitud

Este módulo enseña cómo revisar el estado de una solicitud después de enviarla.

Procedimiento:

1. Abra la página pública de seguimiento.
2. Escriba el número o código de seguimiento recibido al enviar la solicitud.
3. Lea el estado mostrado.
4. Revise si el sistema pide más información o indica que la solicitud está en revisión.
5. Si el estado no cambia durante un tiempo razonable, consulte la sección 16.

Estados comunes:

1. Enviada: la solicitud fue recibida.
2. En revisión: un operador o equipo autorizado está revisando la información.
3. Requiere comprobación de campo: la ubicación necesita revisión adicional por personal de campo.
4. Listo para aprobación: el caso está preparado para decisión autorizada.
5. Publicado: la información pública aprobada está disponible.
6. Rechazado o cerrado: la solicitud no avanzó; revise la explicación si está disponible.

## 10. Módulo 5: entender el estado público

Este módulo explica por qué algunas solicitudes no aparecen como información pública inmediatamente.

Ideas principales:

1. Una ubicación enviada es una solicitud, no una publicación final.
2. La revisión interna comprueba calidad, duplicados y evidencia.
3. El bloqueo de publicación pública protege la información hasta la decisión autorizada.
4. La señalización, certificados y exportaciones oficiales se tratan después de esa decisión.

Diferencia entre etapas:

1. Ubicación enviada: el usuario envió la información.
2. Revisión interna: operadores revisan calidad, duplicados y evidencia de ubicación.
3. Listo para aprobación: el caso puede pasar a decisión autorizada.
4. Registro oficial publicado: la información aprobada está disponible para consulta pública.

## 11. Ejercicios prácticos

Ejercicio 1: preparar una solicitud de ubicación.

Objetivo: practicar cómo reunir información antes de enviar.

Escenario: una familia quiere enviar la ubicación de su vivienda.

Pasos:

1. Escriba una descripción clara del lugar.
2. Identifique una referencia cercana.
3. Explique qué información no debe escribirse en notas públicas.
4. Revise qué significa la precisión GPS.

Resultado esperado: el participante puede preparar una solicitud clara y segura.

Ejercicio 2: comprobar un código.

Objetivo: practicar la lectura de un resultado de comprobación.

Escenario: una empresa recibe un código de dirección y desea comprobarlo.

Pasos:

1. Escriba el código en la página de comprobación.
2. Lea el estado público.
3. Explique si el código está publicado o si puede estar pendiente.
4. Indique qué hacer si no aparece.

Resultado esperado: el participante no confunde código reconocido con publicación oficial final.

Ejercicio 3: seguimiento responsable.

Objetivo: practicar seguimiento de forma segura.

Escenario: una persona quiere preguntar por el estado de su solicitud.

Pasos:

1. Use el número de seguimiento.
2. Lea el estado.
3. Prepare una pregunta breve si necesita ayuda.
4. Evite repetir datos completos que no sean necesarios.

Resultado esperado: el participante sabe pedir ayuda de forma segura.

## 12. Errores comunes

1. Enviar el punto sin revisar el mapa. Esto puede ubicar el registro en el lugar equivocado. La forma correcta es confirmar el punto antes de enviar.
2. Escribir notas vagas. Esto dificulta la revisión. La forma correcta es usar referencias claras y verificables.
3. Incluir datos sensibles completos. Esto aumenta el riesgo de exposición. La forma correcta es usar solo información necesaria.
4. Pensar que la solicitud ya es oficial. Esto confunde el proceso público. La forma correcta es revisar el estado.
5. Compartir seguimiento sin control. Esto puede exponer información de la solicitud. La forma correcta es compartir solo con personas autorizadas.

## 13. Solución de problemas

1. Si el GPS no funciona, intente nuevamente en un lugar abierto o use la corrección manual si está disponible.
2. Si el punto aparece lejos del lugar real, mueva el punto manualmente antes de enviar.
3. Si el código no se reconoce, revise letras, números y guiones.
4. Si la solicitud no aparece, confirme el número de seguimiento y vuelva a intentar.
5. Si el estado no cambia, use la sección 16 con el número de seguimiento.
6. Si la información pública parece incorrecta, use el flujo de corrección pública si está disponible.

## 16. Soporte y contacto

Para ayuda durante el piloto controlado, contacte al equipo de soporte operativo indicado por BeCore o por la institución responsable de la capacitación.

Al pedir ayuda, incluya el número o código de seguimiento si lo tiene, una descripción breve del problema, una captura o explicación del mensaje visto sin contraseñas ni datos sensibles completos, y la provincia o zona general relacionada con la solicitud.

Este manual no reemplaza instrucciones oficiales futuras. Si la institución responsable emite una norma o procedimiento actualizado, esa norma tiene prioridad.

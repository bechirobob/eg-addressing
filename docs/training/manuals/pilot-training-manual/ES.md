## 1. Cómo usar este manual

Este manual capacita al capacitador para dirigir sesiones estructuradas que enseñen los flujos correctos sin crear expectativas oficiales falsas.

Use el manual en orden durante una sesión guiada y después como referencia. Cada módulo explica el trabajo principal, los pasos correctos y los errores que deben evitarse.

Los ejemplos son de capacitación y no sustituyen instrucciones oficiales futuras.

## 2. Audiencia y responsabilidades

Capacitadores, supervisores y coordinadores que dirigen sesiones de capacitación del piloto.

1. Cumplir el rol asignado sin invadir decisiones de otros roles.
2. Usar solamente datos necesarios para el trabajo.
3. Mantener clara la diferencia entre revisión, decisión y publicación.
4. Registrar observaciones de forma breve y verificable.
5. Escalar dudas antes de forzar una acción.

## 3. Resultados de capacitación

Al terminar este manual, el participante debe poder:

1. Explicar el límite de su rol.
2. Seguir el flujo diario correcto.
3. Reconocer información sensible.
4. Mantener evidencia o notas comprensibles.
5. Saber cuándo escalar un caso.

## 4. Términos clave

Registro oficial: información revisada dentro del flujo institucional.

Listo para aprobación: estado que indica preparación para decisión autorizada.

Evidencia de ubicación: información que ayuda a confirmar dónde está un lugar.

Bloqueo de publicación pública: control que evita publicación antes de autorización.

Historial del registro: secuencia de acciones visibles para revisión y auditoría.

## 5. Reglas de privacidad y seguridad

No coloque contraseñas, números completos de identidad, datos bancarios ni información privada innecesaria en notas, ejemplos o capturas de capacitación.

Reglas básicas:

1. Use datos reales solo en el sistema protegido cuando el rol lo requiera.
2. Use ejemplos ficticios o aprobados en capacitación.
3. No comparta capturas con datos privados.
4. No copie información protegida a canales públicos.
5. Si una situación es sensible, consulte al supervisor.

## 6. Módulo 1: preparación de la sesión

Este módulo enseña a preparar una sesión clara antes de que lleguen participantes.

Procedimiento:

1. Confirme audiencia y rol enfocado.
2. Prepare ejemplos seguros de capacitación.
3. Revise proyector o materiales impresos.
4. Indique el límite de piloto controlado.
5. Evite usar registros privados reales.

Ejemplo de capacitación:
El participante recibe un caso de capacitación relacionado con preparación de la sesión. Debe seguir los pasos, explicar el motivo de cada decisión y dejar el caso listo para el siguiente rol sin añadir información innecesaria.

Errores que se deben evitar:
1. Compartir detalles de acceso fuera del canal aprobado.
2. Dejar activo un acceso antiguo tras cambio de rol.
3. Cambiar más de un control antes de verificar el resultado.
4. Registrar valores secretos en notas o capturas.

## 7. Módulo 2: enseñar el flujo

Este módulo enseña a explicar la plataforma como secuencia de roles.

Procedimiento:

1. Comience con solicitud pública.
2. Muestre evidencia de campo.
3. Explique preparación de registro.
4. Explique revisión institucional.
5. Termine con controles de publicación.

Ejemplo de capacitación:
El participante recibe un caso de capacitación relacionado con enseñar el flujo. Debe seguir los pasos, explicar el motivo de cada decisión y dejar el caso listo para el siguiente rol sin añadir información innecesaria.

Errores que se deben evitar:
1. Saltar el límite del rol porque el caso parece simple.
2. Dejar la siguiente acción poco clara.
3. Añadir datos privados que el siguiente rol no necesita.
4. Prometer un resultado que pertenece a otro flujo.

## 8. Módulo 3: facilitación de práctica

Este módulo enseña a dirigir ejercicios sin exponer datos sensibles.

Procedimiento:

1. Asigne un escenario de capacitación.
2. Permita que participantes completen pasos en orden.
3. Pause para preguntas tras cada módulo.
4. Corrija malentendidos inmediatamente.
5. Mantenga ejemplos ficticios o aprobados.

## 11. Ejercicios prácticos

Ejercicio 1: Revise un caso de capacitación y diga qué información falta.

Ejercicio 2: Explique qué rol debe actuar después y por qué.

Ejercicio 3: Identifique una frase que podría exponer información sensible y reescríbala.

Ejercicio 4: Prepare una nota breve que ayude al siguiente revisor.

## 12. Errores comunes

1. Confundir avance de revisión con aprobación final.
2. Duplicar la misma advertencia en varias notas.
3. Dejar el caso sin siguiente acción clara.
4. Usar lenguaje técnico cuando basta una explicación simple.
5. Guardar evidencia fuera del flujo protegido.

## 13. Solución de problemas

1. Si falta evidencia, devuelva el caso al rol correcto.
2. Si el estado no coincide con la evidencia, pause el avance y pida revisión.
3. Si aparece información sensible, retírela del texto público y escale el caso.
4. Si no sabe qué hacer, no fuerce una decisión; registre la duda.
5. Si el sistema no responde, conserve el identificador del caso y contacte soporte autorizado.

## 14. Lista de evaluación

1. El participante puede explicar su rol.
2. El participante puede completar el flujo principal.
3. El participante reconoce datos sensibles.
4. El participante mantiene notas breves y útiles.
5. El participante sabe cuándo escalar.

## 16. Soporte y contacto

Para ayuda durante el piloto controlado, contacte al equipo de soporte operativo indicado por BeCore o por la institución responsable de la capacitación.

Al pedir ayuda, incluya el identificador del caso si está disponible, una descripción breve del problema y el rol desde el que trabaja. No incluya contraseñas ni datos sensibles completos.

Si la institución responsable emite una norma o procedimiento actualizado, esa instrucción tiene prioridad.

# Glosario de capacitación — Español

Este glosario normaliza los términos visibles para las versiones españolas de los manuales.

| Término | Significado | Uso en capacitación |
|---|---|---|
| Bloqueo de aprobación | Control que impide avanzar un registro hasta que la autoridad correspondiente lo apruebe. | Usar en lugar de términos técnicos como `release gate`. |
| Bloqueo de publicación pública | Control que impide publicar registros, certificados, señalización o exportaciones antes de la aprobación correspondiente. | Usar en la guía de publicación y emisión oficial. |
| Código de dirección | Código público vinculado a una ubicación enviada o a un registro aprobado. | Usar para búsqueda, señalización, prueba pública y seguimiento. |
| Comprobación de campo | Revisión realizada por personal de campo sobre una ubicación o punto de dirección. | Usar en procedimientos operativos. |
| Ejemplo de capacitación | Ejemplo ficticio o controlado utilizado para enseñar. | Usar en ejercicios y capturas de pantalla. |
| Evidencia de ubicación | Información que respalda dónde se encuentra un lugar, como punto GPS, notas de campo y adjuntos seguros. | Usar en lugar de lenguaje GIS técnico. |
| Evidencia de mapa | Evidencia basada en mapa, coordenadas o geometría para revisar una ubicación. | Usar cuando se explique el apoyo cartográfico. |
| Historial del registro | Secuencia de acciones y actualizaciones de un registro. | Usar en lugar de línea temporal técnica. |
| Índice de referencia | Sección alfabética al final del manual para consultar temas, términos y procedimientos. | Obligatorio en todos los manuales. |
| Lista de contenidos | Lista inicial de secciones del manual. | Obligatoria en todos los manuales. |
| Listo para aprobación | Estado en el que un caso está preparado para revisión autorizada, pero no es público automáticamente. | Usar en lugar de `registry-ready`. |
| Precisión GPS | Estimación de precisión del punto de ubicación capturado. | Usar al enseñar calidad de captura. |
| Registro oficial | Registro de dirección revisado dentro del flujo oficial de registro. | Usar en lugar de `canonical record`. |
| Registro de actividad | Registro de acciones importantes realizadas en el sistema. | Usar para capacitación operativa; explicar auditoría formal solo cuando sea necesario. |
| Sesión iniciada | Acceso activo de un usuario que ha iniciado sesión. | Usar en lugar de token o términos técnicos de autenticación. |
| Cerrar sesión del usuario en todas partes | Finalizar todas las sesiones iniciadas de un usuario. | Usar en manuales de administración. |
| Sesiones iniciadas | Lugares o dispositivos donde un usuario está conectado. | Usar en lugar de sesiones activas técnicas. |
| Estado público | Indica si un registro no es público, está retenido internamente o está publicado. | Usar en lugar de `publication state`. |
| Ubicación enviada | Solicitud de ubicación enviada para revisión. | Usar en lugar de `geotag submission`. |

## Términos que se deben evitar en manuales generales

Evitar estos términos salvo en manuales técnicos y con explicación clara:

- canonical;
- registry-ready;
- mutation;
- auth token;
- session token;
- endpoint;
- schema;
- fixture;
- PostGIS;
- raw API response.

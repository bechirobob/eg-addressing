# Training Materials Package

This folder defines the official training-material system for the Equatorial Guinea National Digital Addressing platform.

## Purpose

The training package turns the platform into teachable, repeatable operating knowledge for public users, field teams, registry staff, institutional reviewers, administrators, and trainers.

## Language rule

Every training manual must be produced as a paired set:

- Spanish version for government-facing training and local operations.
- English version for BeCore review, partner coordination, and bilingual support.

Spanish is the primary public/government training language. English is the review and coordination copy.

## Required manual structure

Every manual must include:

1. Cover
2. Document control page
3. Table of contents
4. How to use this manual
5. Audience and responsibilities
6. Key terms
7. Training modules
8. Step-by-step procedures
9. Practice exercises
10. Common mistakes
11. Troubleshooting
12. Assessment checklist
13. Reference index
14. Support/contact page

## Core files

- `training-pack-blueprint.md` — scope, manual list, sequencing, acceptance criteria.
- `pdf-style-guide.md` — layout, tone, page structure, bilingual PDF rules.
- `glossary-en.md` — English training glossary.
- `glossary-es.md` — Spanish training glossary.

## Output convention

Final PDF outputs should be generated under manual-specific folders later, for example:

```text
docs/training/manuals/public-user-guide/output/EG-Addressing-Public-User-Guide-ES.pdf
docs/training/manuals/public-user-guide/output/EG-Addressing-Public-User-Guide-EN.pdf
```

Do not publish drafts as final PDFs until the checklist in `pdf-style-guide.md` passes.

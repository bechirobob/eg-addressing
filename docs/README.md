# Docs Guide

This folder holds durable planning, architecture, and delivery documents for the addressing platform.

## Conventions
- Keep active planning and architecture docs here.
- Keep generated proposal assets that are part of the product story under `docs/source-proposals/`.
- Keep durable training-material standards and manual sources under `docs/training/`.
- Keep temporary operator notes in local `knowledge/`, not here.
- Prefer updating an existing document over creating near-duplicate plan files.

- `implementation-bootstrap-plan.md`
- `starter-code-implementation-plan.md`
- `national-branding-blueprint.md`
- `roadmap-gap-closure-plan.md`

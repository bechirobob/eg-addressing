# Artifacts Guide

This folder stores generated visuals, PDFs, and legacy reference outputs that support the project narrative.

## Conventions
- Keep current presentation assets at the top level when they are still actively referenced.
- Keep superseded but useful historical material under `legacy/`.
- Do not put secrets, runtime exports, or local-only mission logs here.
- Large generated assets should earn their keep; prune stale files instead of hoarding them.
